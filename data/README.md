`bip39-english.txt` is the 2048-word English BIP39 list from
https://github.com/bitcoin/bips/blob/master/bip-0039/english.txt
(downloaded 2026-10-30), used only to reject possible recovery phrases.

and Sean Bowe. No user recovery phrases are stored here.
